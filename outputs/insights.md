# Key Insights

- Within the analyzed dataset, the 4-2-3-1 formation shows the strongest offensive performance across the selected KPIs.
- A higher number of shots does not necessarily result in more goals.
- Shots on target provide a more reliable indication of offensive quality than total shots alone.
- Goal-scoring efficiency highlights how effectively different formations convert shooting opportunities into goals.
- The analysis demonstrates how SQL can be used to investigate tactical performance using structured relational data.
- The findings should be interpreted within the limitations of the available sample dataset and can be extended with real-world data in future versions.
