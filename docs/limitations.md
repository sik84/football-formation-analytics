# Limitations

The main limitation of this project is the limited size of the available sample dataset. While the analysis provides useful insights into the selected matches and formations, the results cannot be generalized to football formations overall. A larger dataset covering more matches, teams, leagues, and seasons would be necessary to identify more robust patterns.

Another limitation is the absence of additional variables that would be necessary to investigate the research question more comprehensively. While the selected KPIs provide valuable insights into offensive performance, they do not capture all factors that may influence tactical success.

Several potentially influential variables are not included in the current dataset, such as opposition strength, player quality, home advantage, and set-piece situations. Including these factors could provide a more comprehensive understanding of the relationship between tactical formations and offensive performance in future versions of the project.
